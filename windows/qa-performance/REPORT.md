# Screenline 0.4.1 性能对照

同机、同组自生成 3840 × 2160 图片，每版三次，表中取中位数。

| 测量 | 0.4.0 | 0.4.1 | 降低 |
|---|---:|---:|---:|
| 图片收纳总耗时 | 787.22 ms | 406.94 ms | 48.3% |
| 收纳期间 UI 心跳最大间隔 | 787.28 ms | 31.57 ms | 96.0% |
| 重复图片收纳耗时 | 539.63 ms | 29.54 ms | 94.5% |

UI 心跳采用 16ms 的 Input 优先级 DispatcherTimer。它用于观察长时间阻塞，不是屏幕呈现帧率。
图片生成及屏幕像素读取不计入收纳耗时；后台编码仍需时间，但期间可继续处理界面消息。
结果只代表本机合成图片测试，不保证所有图片、设备或显示器达到同样数值。

原始记录：baseline/image-pipeline.json、current/image-pipeline.json。二进制 SHA256 及汇总：report.json。
